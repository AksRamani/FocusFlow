# FocusFlow: To-Do List, Kanban View & Task Management (Chrome Extension)

A minimalist dark-themed to-do list and Kanban view task manager that replaces your Chrome homepage / New Tab.

## ✨ Features & Keyword Highlights

- **Todo on Home Page / New Tab:** Opens immediately on every new tab with a distraction-free dark layout, live ambient clock, and task completion meter.
- **Bulk Task Add:** Paste dozens of tasks at once. Auto-cleans bullet points, numbers, checkboxes, and recognizes smart priority tags (`[urgent]`, `[high]`, `!`, `!!`).
- **Single Task Add:** Press `N` or click New Task for fast single task add with notes and priority.
- **Kanban View with 3 Focus Tabs:** View all 3 columns (To Do, In Progress, Done) or switch to focused single tabs with real-time counters.
- **Search & Filtering:** Real-time search bar to find any task instantly by keyword, plus priority filter dropdown.
- **Drag-and-Drop Task Management:** Smooth reordering and column transfers.
- **100% Offline & Private:** Stored locally in `chrome.storage.local`.

## 🚀 How to Install Locally

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** (top left).
4. Select `C:\Users\MTPC-511\.gemini\antigravity\scratch\minimal-kanban-newtab`.
